### 在既有專案基礎上進行開發

僅在符合以下條件時允許：

- 新增加的功能必須具備重大且實質性的改動。評審僅會針對黑客松期間完成的作品內容進行評分。
- 於新的公開儲存庫 (public repository) 中開發。
- 須在 README 及作品提交表單中提供既有儲存庫的連結。
- 須在 README 及作品提交表單中清楚說明黑客松期間完成的開發內容。
