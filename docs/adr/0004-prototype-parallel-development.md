# ADR 0004：原型優先、異步開發與持續試接

> Status: accepted — 使用者於本次對話同意三類工作與共用接口討論表，並授權修改；不代表 D1～D9 或完整功能已核准。
> Partially supersedes: [ADR 0003](0003-real-slice-delivery.md) 的開工限制，增加開發版試接；正式交付與 SP-01 保留模式不變。

## 決策

目標是比賽期間最快取得真實可用 prototype，接受局部接口返工。SP-01 按原安排完整開發，下游優先適配其已有介面，不要求提前切片或承接新增能力。SP-02～04 依 [workflow](../../workflow.md) 分為 A 可獨立、B 內部先做並同步討論接口、C 先決定受影響部分。A／B 不等待整份契約凍結；C 只阻擋依賴該答案的工作。

工作分類見[原型工作表](../product/prototype-work-plan.md)，跨組問題使用[接口討論表](../product/interface-discussion-board.md)。表單是協調入口，不是第二份契約；產品、責任、安全及公開 schema 的決策仍先核准並更新對應權威。

允許依 workflow 在隔離環境使用可辨識的真實開發版本試接，不必等上游整份合併。開發版接通不等於正式整合、Ticket 結案或 S01-FULL；正式依賴仍需 main 證據。禁止以替身、固定通過結果或人工批准候選冒充真實路徑。

## 取捨

以接口調整成本換取等待時間減少；由人類指定整合協調人，持續追蹤真實版本與最早可試接點，避免最後一天才整合。未決產品數值、責任及恢復語意不自行補定。安全隔離、錯誤停鐘、五版上限、正式驗收及人類合併授權不放寬。

本 ADR 不自動建立工作單、指派人名、修改 SP-01 分支，亦不授權 push／merge。原型只證明已展示的真實範圍；完整完成仍依 ACCEPTANCE。
