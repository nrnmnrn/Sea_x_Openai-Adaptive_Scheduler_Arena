# ADR 0003：真實切片交付與 SP-01 保留模式

> Status: partially superseded — 開工限制與開發版試接依 [ADR 0004](0004-prototype-parallel-development.md)；本文件的正式交付、分支及 SP-01 保留模式繼續適用。
> Supersedes: [ADR 0002](0002-one-branch-per-sub-prd.md) 對 SP-02～04 的單分支限制；SP-01 保留原模式。

## 決策

目前已在比賽開發期間，SP-01 已有人完整開發。維持其單一 branch／PR 與完整交付，不要求提前拆分。SP-02～04 每份保留唯一 Owner／parent issue，但每個核准的真實功能切片以獨立 Ticket、短期 branch／PR 交付。

切片正式整合等待實際需要的上游成果 merge 並在 `main` 驗證；SP-01 上游成果仍指整份交付。切片自身亦需人類授權合併及 `main` 驗證才結案。整份子 PRD 保留完整驗收，不以切片累計取代。精確步驟以 [workflow](../../workflow.md) 為流程來源。

## 取捨與邊界

真實能力分段到位，可縮短下游等待，但增加 PR 審查、相容性與共享檔案協調成本。不使用測試替身作為本次平行開發就緒證據；原型 A／B 開工與真實未合併版本試接依 ADR 0004；正式交付仍遵守上述條件。

保留 2–3 張 Ticket 標準、4–5 張特別核准及超過 5 張不得核准的規則。允許受阻交接後轉做其他已準備工作，但不關閉受阻 Ticket。此決策只核准流程，不核准調查報告的產品預設值、新資料 schema 或責任轉移。
