# 共用接口討論表

## 表單定位與填寫規則

本表供四組異步討論，不是已核准契約、產品預設或完成證據。流程見 [workflow](../../workflow.md)，可先做的部分見[工作分類](prototype-work-plan.md)。產品缺口仍以 [D1～D9](adaptation-decisions.md)追蹤；接口權威是 [backend](../contracts/backend-contract.md) 與 [H1～H8](../contracts/adaptation-contract.md)。本輪未查驗組員分支／服務，不將文件內容冒充實作現況。

整合協調人：**待使用者／main 負責人指定**。各列人名、版本、需答案時間由團隊填寫；不要求 SP-01 改原排程。每個問題一列，需要拆分則沿用 ID 加後綴並同步引用，不新增產品權威。

狀態依序：待討論 → 已決定（附核可及權威落點）→ 已實作（附版本）→ 開發版已接通（附真實證據）→ 正式已整合（附 main 證據）。問題重開時保留舊結論與版本。單純命名／格式適配且不改語意，可由雙方確認並記錄；產品、責任、安全、公開 schema 變更須人類核准並更新權威後使用。
